# 三至五章结构复盘与重写提案

2026-09-24，依据用户完整试玩反馈。本文是诊断与重写提案，不是已经实现的新剧情。现有三至五章不再作为值得沿用的节奏范本；暂不要沿旧第五章继续扩写第六章。

## 原作核对

核对本机整理的《回程 故事原文与创作讨论》S01—S03。小说节号与游戏章号不对应。

原作S02结尾：主角独自回家，看到旧快递单和“放门口就行，家里有人”，听见屋内向外敲门。S03：报警，民警搜屋无人，以门体结构等正常可能解释声音；房东解释改建户型，卧室墙后可能是501的一部分。民警和房东离开后，主角自行查户型、查看通风口，与墙后声音接触。原作后面确实走向身份、轨迹等超自然解释，但这里没有游戏当前的多人持续通话核位链。

当前游戏第二章加入陈屿声称在门口、主角与房东寻人；第三章放大为敞门与关门的实时矛盾；第四章增加照片核位、静音试验；第五章增加多人听见第一夜旧话的语音。这是改编扩写，不能归咎于照搬原作。

## 问题诊断

1. 三章共用一个场景、一个行动目标：通话找陈屿。照片、静音、语音只是替同一异常补证，地点、关系和行动后果变化太少。
2. 文字没有说“平行时空”，戏剧结构却提前提供了这个最省力的答案。照片时间未鉴定、声音未作声纹鉴定等作者备注，不能抵消多人见证与连续排除普通解释的效果。
3. 把陈屿固定成持续求救的受困者，过早消耗了第一章“他到底知道什么”的人物悬疑。
4. 安心段落里的喝水、擦汗、换手、扶门，重复时变成等待手续。心理细节应改变决定或揭示具体恐惧，不应给每句电话配一组动作。
5. 旁人在场不是问题；让他们长时间陪着完成异常实验才是问题。普通人的协助可以解决真正的问题，不能只充当见证者或作者替正常解释辩护的嘴。
6. 追加省略号修复了阅读先后，却不能修复剧情拖延。结构重写后要重新审视停顿数量，不能逐字搬回全部新增阅读节点。

## 建议保留与撤回

保留第一章已获认可的人物关系、声音尺度和“你出来了”；第二章保留晚饭失约与门内声响的压力。第二章结尾也需联动检查，避免提前写死双方听见的是同一次敲击。

撤掉现有第三章后半至第五章连续三章的敞门/关门证明链。门口照片确认地点、静音后回应主角声音、录音精确重放昨夜求助，均不作为下一稿必须兑现的事实。不是挨个换一种说法后保留整条链。

陈屿的恐惧可以真实，但所在地点、为何去那里、掌握了多少事情不能一起透明化。保留让他有机会亲口解释的行动目标；不能用手机连续故障或永远不发照片拖延验证。

## 三章重新分工（候选结构）

第三章：完成第二章已经承诺的处理，搜屋和核查给出实质结果，主角离开现场。只留下一个具体、可追查的生活矛盾；不安排实时开关门比较。目标是暂时恢复行动能力，而非在屋内再困两章。

第四章：把主动权交还主角，追查陈屿的行动或房屋的一个具体使用痕迹；获得一条真的有用的解释，并据此作出决定。正常工作与生活可以回来，危险从解释中的一个小空缺渗入。不能同时添加住户、门牌、时间、照片、记忆五类新谜题。

第五章：兑现前章决定的后果。高潮改变主角对自己做过某件事的理解，而不公开展示空间机制。一次矛盾足够，随后必须有人采取新行动，结束长时间守着手机。

## 微恐事件设计约束与候选示例

优先深化已有的“屋内是否有人／陈屿知道什么”，不要新增怪谈目录。可选的写法示例（非定稿，不要直接全部加入）：

主角认为一个很轻的声音来自隔壁。他将邻居的一句普通回答当成确认，终于肯离开；稍后翻看完整消息，才发现对方确认的是昨晚听见他在屋里说话，而非对方发出的声响。恐怖来自主角曾凭一个误解作出安心决定。必须先核对既有通话时间，不能把主角确实打过电话的时段写成“绝不可能说话”的证据。

另一个更简洁的方向：邻居确实听见主角昨夜求助，却顺口说“我以为你们已经走了”。只留“你们”这一个不协调处，允许对方把电话声听成第二个人。不要紧接着确认有两个人，更不能补上目击双张明远。若采用，应让这一细节推动查声音来源，而不是立刻去问第二个邻居再获得一个新谜题。

这些示例旨在规定异常的强度，不是用漂亮怪句代替因果设计。落稿前必须确定：实际发生了什么、每个人能知道什么、为何作出该判断、后面如何回收。没有作者内部答案的细节不能因“吓人”而加入。

## 改稿验收

每章应改变至少一项：目标、可采取的行动、对人的信任或已知事实。删掉一段后若只少了等待和发抖，应压缩。玩家仍能提出不同解释，但不能仅靠角色刻意不问显而易见的问题来维持悬念。超自然可以是最终真相，前期不能通过一套公开实验直接呈现机制。

本轮只完成原作对照和结构复盘，未覆盖现有可玩版本。重写会改变阅读节点语义，应单独处理版本和存档，不伪称旧三至五章进度能无缝导入新剧情。
