# 黑幕转场修复

2026-09-24。用户反馈楼梯及其他黑幕段落淡出前会突然闪回卧室。

原因：背景元素切到 data-scene=black 后，没有对应的图片定义，回落到基础样式里的卧室图；opacity 再缓慢降到零，造成错误画面露出。

修复：剧情场景仍可为 black，但模型独立保存最后一个可见背景及镜头。渲染只淡出原背景，不把图片切到默认卧室。开篇没有前景时明确使用无图片；黑幕读档、回退立即恢复黑屏，返回标题再显示标题背景。淡出期间保留已有镜头与滤镜。

新增模型恢复检查与实际 Electron 验证：逐一经过全部显式黑幕转场，比较转场前、淡出中背景图不变，结束后透明度为零，并核对黑幕读档和开篇无默认图。隐藏窗口需要等待实际动画帧，不能把未推进的合成帧当作最终画面。

故事文本、节点和存档格式未变。本修复同步三章稳定版与后续开发版。
