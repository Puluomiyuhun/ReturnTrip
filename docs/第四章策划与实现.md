# 第四章《先别挂》策划与实现

2026-09-24。本章是 0.8 开发稿。前三章源稿保持不变；开发在 chapter4-draft 分支进行，便于用户继续测试 0.7。

## 本章要完成的事

兑现上一章拍照和位置核查的请求；让搜寻得到实际进展；将“门是否开着”的争执转成“陈屿依据什么作出行动”。不增加身份谜题、知情组织或异常守则，不解释平行世界。

章节约 2400 字、122 个阅读段落，时间从 20:49 到 21:00 后。没有新增敲击或突发音效。高潮通过对白和手机状态建立，十秒等待是叙述时间，不强制玩家等待十秒。

## 节奏

1. 接住上一章：老唐扶门，主角松手。照片正常收到，玩家可以打开查看，也能在回看中再次查看。照片只有亮灯楼道、关着的502、楼梯和窗户，没有暗藏惊悚图像。
2. 正常解释开始工作：相似楼栋可能认错，民警分头核查。主角与陈屿短暂恢复熟人说话的语气。椅子、湿袜子、充电宝、邻居扔垃圾提供生活节奏，不各自附带疑点。
3. 核查取得结果：相邻单元的门窗方向不符；房东根据布局更倾向照片拍的是这边。缩小范围，但不能据此证明照片拍摄时间或陈屿当前就在门口。发送时间不是拍摄时间。
4. 尝试救人：主角引导陈屿下两级楼梯，以为终于不必再争论开门。陈屿却说又听见让他等的话。人物先尝试延迟、混音等正常解释，核查是否使用免提。
5. 高潮：主角关掉自己的麦克风，陈屿仍作出应答，随后认为主角说了“现在出来”。现场只听见陈屿的应答，不播放所谓另一个张明远的声音，不展示另一人。主角失去靠通话指路的把握，只能要求别挂。

## 证据边界

确定呈现：收到照片；现场门敞开；相邻单元核查结果；陈屿同意移动并称走了两级；男主关闭自己的麦克风；其间电话里仍能听见陈屿；陈屿说出等候与“现在出来”。

只来自陈屿陈述：声音从门内传出、他把那句话理解为张明远说的。没有第三方核验门内声音，没有确认“第二个张明远”，没有证明通信延迟等解释已全部排除。

配图复用已有闭门楼道背景，作为照片内容的视觉示意；仅在附件面板展示，不替换主角所处的开门场景。不能把素材复用本身当成两张照片像素一致的证据。图中门牌、窗和楼梯可见，文字不凭空增加独特标记。后续若制作手机取景差分，也必须保留布局连续性。

## 第五章必须承接

- 继续搜寻与位置验证。不能让出去核查的民警消失，不能一直让陈屿只说怕而拒绝任何行动。
- 现有照片没有给出可靠拍摄时间。若要证明即时性，须设计一次能核对的当下动作或取景请求，不能由发送时间替代。
- “现在出来”的陈述还不是声源机制的证明。下一步可以核查通信重复/延迟，但不应把所有可疑点都轻率解释成设备故障或再加一个新怪现象。
- 主角已经不敢随便指路，后续行动应体现这份顾虑，不得下一章又无事发生地继续喊“往下走”。
- 不能把本章写成万能“不要回答”规则。保持联络在本章仍是帮助陈屿的必要行动。
