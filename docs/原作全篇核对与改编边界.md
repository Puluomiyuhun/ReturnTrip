## 原作的叙述性诡计

核心并非单纯“平行空间真的存在”，而是第一人称叙述与经历归属的错置：记忆可以真实，却不属于当前这个人的过去；不同版本的人都真实，不能凭熟悉程度、脸、疤或回忆分出唯一真品。

S08将第一夜“你出来了？”的指向翻转：最初以为是在问走出卧室的主角，后来读到墙里那一侧才重新理解。S09确实出现重叠但无法互相触碰/看见的房间与人物。因此，上一轮“原作没有这种现象”的泛化是错误的；准确说法是：原作没有当前AVG这种前段多人守门、持续验证陈屿位置的扩写链，类似机制到后段才揭开。

终章把交换与循环落在人对孤独、被遗忘的恐惧上。结束并非打败怪物，而是停止借另一个人的位置与名字让自己回来。公交卡回归普通交通卡，敲声回归普通声音，是结局的结构性回收。

## 陈屿的角色线

| 原文位置 | 实际呈现 | 改编意义 |
| --- | --- | --- |
| S01—S02 | 主角记得他是同学，近期重新联系；他追问哪面墙，说“那没事了”“你出来了”，随后否认或以喝多解释 | 有关心与熟悉，也有超出正常知情范围的信息；不是待救NPC |
| S03 | 毕业合影/群成员缺位，朋友圈少正脸；他提前知道主角约房东看501；发出含危险细节的照片后才叫主角别放大 | 帮助与诱导并存，不能提前替他解释成纯善意 |
| S04—S06 | 手机中的陈屿与门外的声音不能简单合并；他引导找文件、卡和视频，证据逐渐否定稳定的“第四室友”记忆 | 姓名显示、声音识别和回忆都不是上帝视角认证 |
| S07 | 承认阻止主角回去有自保成分；说自己不知道是谁、只能依托主角记忆，曾被忘记多次 | 真实的疲惫和情感不消除其行为对主角的危险 |
| S08—S09 | 墙后自称张明远的人不应直接等同于所有叫“陈屿”的人；命名、记忆、2008/2015的闭环逐步揭开 | 名字、位置、不同出现不能偷换成一个稳定肉身的连续行动史 |
| S10与D01—D03 | “虚构的名字，也可以是真的关系”；主角最终不再把这个名字传下去 | 既不能改成纯恶人，也不能仅是被救出来的好朋友 |

陈屿不是“绝不能被任何人看见”的鬼。原作有照片、实体出现及真实关系。问题在于，新增一次由可靠第三方找到并确认的见面，会新增哪一条客观事实，之后凭什么回收。没有完成这项设计前，不能把它当成方便收尾的手续。

## 公交卡的完整作用链

| 原文位置 | 道具/数字表现 | 当时的意义与后续用途 |
| --- | --- | --- |
| S01 | 床头柜后捡到蓝色旧卡，背面“周”；放柜上后，早晨外套口袋里找到卡 | 普通遗留物→物件与记忆位置不符；“周”把周启明提前埋入故事 |
| S02 | 完整卡号3104 7719 0832；面馆老板误叫“小周”，快递单收件人也留“周” | 姓名与物证形成贯穿线，数字先只是可记住的事实 |
| S03—S04 | 旧照片中露出蓝卡；陈屿问末四位；记事本写“记住公交卡”；卡背“周”下刮出“明远”；08:32对应一次现场事件 | 卡并非无主物，开始触及主角身份；时间解读只是阶段性线索 |
| S05 | 蓝色碎片与缺口拼合，显出32；记事本第32条缺失 | 卡号、碎片、记录之间出现可追查的连接，不是仅报一个神秘数字 |
| S06 | 0832解锁旧手机；32号视频长08:32；卡号0832→0833，随后出现33号视频 | 数字把物证引向核心叙述证据，并提示“单一密码”理解可能不够 |
| S07 | 对31/04/77/19/08/33提出多种解释；末位递减至1、0；计数方向从“谁记得我”翻转为“我还记得谁” | 人物解释会被后续推翻，不可把任何中途说法直接写成系统规则；77在相关问答中未得到明确回答 |
| S08 | 不开门后末位到34，卡背“陈”牵连命名 | 主角行动与已有循环产生差异，不再只是被动读谜题 |
| S09 | “周”“明远”“陈”不同卡并置；提出回程票、目的姓名、回来者编号等理解；2008录像中也有卡 | 主角原以为同一张卡的变化，可能包含不同卡的交换；是视点诡计的实物支点 |
| S10 | 空白卡3104 7719 0800；姓名变化时00→01→02，终章解释为本轮交换名字次数；结束后可正常刷卡，余额17.00 | 道具从贯穿异常的凭证回归日常；不能删去后再仅在结尾补一张卡 |

卡号末位的“回来者编号”与终章“本轮交换名字次数”、中途递减的人际计数，不应未经处理就当成完全一致的技术规则。D01也说标记不必共享一套编码。AVG需先选定简化后的作者内部规则，再区分角色误读与可核对事实；本轮尚未擅自决定最终编码。

还需校订：S01早晨外套中明确写卡背仍是“周”；S09回述却说早晨得到的是“明远”。这是实际文本不一致，不能声称原作早已清楚铺好了多卡交换。若保留多卡，应在游戏可回看的图像、缺角、覆盖墨迹上给出公平证据。

## 现有AVG需要回查的不只是第三章

1. 前两章源稿目前完全没有公交卡和卡号。删减信息量已经删到了主干，需要补回。第一章已获认可的恐惧反应和演出不必推倒，但不能以此为由拒绝补必要伏笔。
2. 当前第一章主角惊恐离屋，已不适合照搬原作“主动挪柜、贴墙、再敲几下”的捡卡过程。可在搬家或整理物品的普通动作中引入卡；这是候选改编，需在落稿时解释卡的可见位置及取得过程。
3. 第一章只需要让玩家见过旧卡、“周”和可回看的号码；不用当场解释所有数字。第二章可安排一次位置或姓名关联，不同时塞进全部原作异常。
4. 第二章李哲直接确认与陈屿长期往来，给“陈屿是稳定旧同学”添了一层外部担保。原作后续大学证据的冲突必须考虑这段新增对白，不能忽略它，也不应无故抹掉已发生的通话。
5. 第二章“陈屿在家门口、两边敲击近似同步”已经把故事导向找人。第三章新写不能继续强化；是否压缩、改写这个桥段，需要与原作主线衔接一起处理。
6. 老唐在原作后段承担旧手机的保管者，不是永远不知情的背景人物。前期正常帮助可以保留，但不能把“他绝对不知情”写成贯穿全篇的铁律。王哥同理：前期可普通，是否保留后段关系崩解必须明确为改编选择。

## 接下来三四章的正确边界

第三章收束当晚的现场处置：检查屋子、确认即时能确认的事实、主角离开、停止守门通话。它不需要结束所有疑点，更不需要安排陈屿被警方找到。陈屿可以仍有联系并具有行动能力，但“在哪、为何知道、为什么引导”保留压力。具体新对白需服务后续身份揭示。

第四章仍按用户要求让主角亲眼遭遇难以用恶作剧安慰自己的异常，但优先使用原作已有、能回收的观察错位。候选是S04肉眼门牌502、手机实时画面501：同一时刻交替看，稳定差异，无面孔、无多人隔空实验；从第三章关于户型/地址的正常核对自然进入。它揭穿“这只是陈屿在逗我”，却不立即宣讲是两条轨迹。

这仍是候选方案，不表示第四章已经重写完成。卡的姓名覆盖是否同章揭露，需要按信息量决定，不能把S04整节所有谜团一次搬来。31/04等完整解释、双主角、墙内视点与第一次“你出来了”的回收应留到合适的后段。

## 新增情节的检查办法

每个新增关键情节先回答：原作依据在哪里；哪些只是角色判断；新增了什么客观事实；它替代或承接哪一条伏笔；后面怎样兑现；是否提前排除了身份/经历上的必要不确定性。

可以改节奏、心理、场景顺序和演出，不能靠临时灵异事件代替原作诡计，也不能以“减少信息量”为名删掉公交卡这样的跨章节支点。
