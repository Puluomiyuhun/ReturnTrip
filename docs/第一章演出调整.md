# 第一章视听演出调整

2026-09-23，基于 0.7 三章稿。此次不改正文和节点顺序，与本轮调整前的 0.7 存档兼容。

## 演出重点

目标是让玩家先感到危险，再跟着主角尝试解释。恐怖集中在已有的敲击和矛盾消息，不额外增加谜题。

| 位置 | 调整 | 目的 |
| --- | --- | --- |
| 卧室第一次敲击 | 空白 0.65 秒后，隔墙声与“咚”一起出现；留出 1.1 秒停顿 | 避免字幕提前替玩家解释声音 |
| 离开卧室后的近处敲击 | 保留环境声，空白 1 秒后落下低电平、较近的敲击；不震动画面，再停 1.4 秒 | 打断“出来就安全了”的预期 |
| 注视床和卧室门 | 局部暗角引导注意，弱化时间、章节和操作栏 | 给玩家盯着空处、等待变化的时间 |
| “你出来了？” | 近处手机提示声，等待 1.5 秒，消息独立出现并停留 2.4 秒；背景和环境声降低 | 把一句话变成对刚才行动的回应 |
| 看墙角、看门、攥手机 | 消息缩成上方条幅，在主角反应期间保留 | 让矛盾一直压在眼前，容纳恐惧反应 |
| “发错了” | 稍短的独立停顿，并保留到后续反应 | 给自我安慰留下时间，不立即恢复轻松 |

卧室雨声更闷、更偏一侧，客厅更开放；隔墙与近处敲击采用不同声向和质感。环境声与敲击、手机提示音分开控制，压低雨声时仍可听清关键声音。这轮没有新增配音或音乐素材。

## 操作与验证

- 可关闭演出停顿；本轮已取消敲击处的画面轻震。
- 等待敲击时连续点击不会提前泄露字幕，环境声也不会为突出敲击而降低。
- 回退、打开设置或切走窗口会取消待播放敲击；读档直接恢复当前画面，不重复播放突发音效。
- 八项 Node 测试通过。Electron 遍历 414 个节点，检查两种尺寸及 30/40px 字号、存读档、保留消息和正文间距、真实演出计时及取消行为，无渲染器错误。

程序与截图验证确认功能和阅读布局。音色衔接、停顿是否合适以及实际恐怖感，仍以完整试听和试玩感受为准。


## 后续音量修订

根据用户反馈，全篇敲击播放增益从首击 0.85 改为 0.003，起音时间常数从 1.2ms 调为 12ms，并延长尾部渐隐。这个增益变化约为 -49dB，不等同于实测听感响度差。雨声不因敲击被压低，敲击定位为雨声下的细小线索。第三章安静场景不增添雨声。
