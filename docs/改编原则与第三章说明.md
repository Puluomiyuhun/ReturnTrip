# 回程 0.7 改编原则与第三章说明

## 本轮目标

提高前期危险感，减少同时需要记忆的疑点，让人物的恐惧影响判断、动作和交流。参考的是用户指出的悬疑作品在前期建立危险的方式，不复刻其中的人物、台词或具体诡计。

## 三条持续适用的写作原则

1. 恐惧要落在当前处境：看不见的床底、退路、握不住的手机、无法确认朋友的位置。声音、停顿和场景为处境服务；不靠每隔几段新增一次异常来维持强度。
2. 保持有限的核心疑问。前三章只围绕敲击从哪里来、陈屿在哪里、双方所说的门是否对应展开。一个线索先经历怀疑、验证、失败和重新理解，再考虑引入下一个。
3. 心理活动由动作承载：伸脚又缩回、抓住同伴袖子、穿错外套、希望朋友只是在恶作剧、害怕耽误救人却不敢独自返回。自我安慰应当短暂有效，随后被具体经历打破，而不是人物持续平静地总结设定。

## 前两章的修改

- 第一章保留主要情节和四个既有停顿点；把“水管不会让我害怕”改成伸脚又收回的动作，减少重复设想鬼物的段落。主角关门后感觉客厅太短，表现退路不足。将楼道的“没有人”改为“没看见人”，不把有限观察写成客观结论。
- 第二章补充留灯、白天进门仍躲在老唐身后、掀床单时抓人、反复试锁等余悸。饭店中增加希望陈屿出现、想骂人又担心他出事的情绪；回家前增加急于救人和害怕返回的冲突。
- 暂时撤下李哲转述的“陈屿提前核对旧地址”。这是有意减少旁支，不代表已排除未来使用；重新引入时须单独安排证据和作用。
- 将联系警方前移到第二章返回小区时；听到屋内敲击后补充报告情况。第三章承接该行动，不让报警停留在口头台词。

## 第三章 门开着

第三章从第二章接通的电话继续，不另起一条调查线。

1. 张明远试图用地址和下楼指令找到陈屿。通话中断，产生折返冲动，最终随房东下楼。
2. 老唐在楼下接应。等待与对普通生活的观察缓和节奏；张明远甚至希望整件事只是朋友的恶作剧。
3. 民警到场，房东确认自己也听见敲击。开门检查未找到人，亮灯、熟悉物品和正常交谈让张明远重新抓住“走错楼”的解释。
4. 陈屿来电。双方再次核对地址，尝试拍照和定位，尚未取得可用图像。陈屿说门仍关着，随后从电话里敲门求助；本地的门一直敞开，楼道没有对应声音。

新增的核心进展只有一个：开门和搜索不能解决双方对同一地址的矛盾。章末没有展示陈屿所在的客观画面，也没有确认“两个世界”或“另一个张明远”。当前观察不足以把地址一致推导为视点位置一致。

## 演出与后续约束

- 开门后的楼道使用独立的 hallway-open 背景，纸箱撑门；避免正文说开门而画面仍显示关门。
- 最后两次敲击使用居中的窄频段手机音色，字幕明确“免提里”，不伪装成本地门板发声。两处短停顿用于留出辨认声音来源的时间，不增加突发巨响。
- 暂未加入公交卡、501 门牌变化、周启明、旧手机视频、实验或记忆改写；不同时启动多个世界观疑点。
- 警方和老唐是现场见证与实际帮助者，不作为无故消失、拒绝帮助或只会阻止主角的工具。第四章须承接通话和搜寻，交代照片请求与旁人核查的后续，不能一笔跳过。
- 当前两方位置、音频传递范围、通话中断原因尚未定为硬规则。后续揭晓需与前三章已经演出的证据对齐。

## 工程范围

剧本编译接入第三章，标题和结束页更新为前三章；版本为 0.7。前两章节点有调整，因此使用独立的 v07 存档命名空间，并拒绝把 v06 进度直接当作新节点恢复。旧存档留在原命名空间，不删除、不覆盖。

正文的主观恐怖效果仍需用户试玩反馈；程序检查只能验证演出和阅读功能，不代表文学效果已定稿。
